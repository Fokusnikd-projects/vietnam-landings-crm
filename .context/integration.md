# Интеграция с Google Таблицей

`src/data.js` задаёт spreadsheet ID, gid и имя листа «Лиды», парсит строку заголовков и сопоставляет `№` с номером текущей строки. `src/App.jsx` загружает диапазон `A:AF`, включая текущие поля интервью и «Статус»; форма редактирования строится по строке заголовков. `src/googleSheet.js` строит A1-адреса изменённых ячеек и отвергает перемещённую строку, чужую правку и формулу. Перед POST `values:batchUpdate` с `RAW` приложение перечитывает значения и формулы изменяемой строки, после записи обновляет данные. Это проверка перед записью, а не атомарная блокировка от гонки между проверкой и POST.

Нельзя отправлять файл `src/snapshot.json` на Vercel или импортировать его в клиентскую сборку. Проверять `npm run build:vercel`, `node --test tests/data.test.mjs tests/googleSheet.test.mjs`, отсутствие имени из снимка в `dist/client` и браузерный поток с мокированным Google API. Реальный OAuth и запись требуют настроенного Client ID.
