# UI и локальные данные

`src/App.jsx` показывает воронку по столбцу «Статус»: на ширине до 1023 px нижние вкладки разделов, строка поиска и липкие стадии; от 1024 px канбан, до 1366 px сайдбар только из иконок. Закрытые скрыты, пока их не включили. Карточка, фильтры и смена стадии — отдельные компоненты в `src/components/`. Фильтры и стадия пишутся в query-строку. Данные листа находятся в памяти вкладки после OAuth; каждые 5 секунд видимая вкладка перечитывает лист, но не трогает открытый черновик правки или выбора стадии. CSV можно открыть только для просмотра. Локальные заметки и OAuth Client ID используют localStorage; токен остаётся в памяти.

`src/styles.css` сохраняет палитру варианта № 3 (сланец, лаванда, коралл) и добавляет нижние листы, липкую панель контактов и зоны нажатия от 44 px. После изменений интерфейса проверить 360 px и 1280 px.
