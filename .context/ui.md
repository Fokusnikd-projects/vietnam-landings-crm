# UI и локальные данные

`src/App.jsx` показывает три группы лидов, поиск, карточку и форму редактирования. Данные листа находятся в памяти вкладки после OAuth; каждые 5 секунд видимая вкладка перечитывает лист. CSV можно открыть только для просмотра. Локальные заметки и OAuth Client ID используют localStorage; токен остаётся в памяти.

`src/styles.css` сохраняет выбранный пользователем вариант № 3. Проверены состояния без подключения и с открытой формой на 1440×1024; скриншоты находятся в `work/qa/` родительской папки задачи. После изменений интерфейса проверить широкую и узкую ширину.
