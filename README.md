# Приоритет — CRM для Google Таблицы

CRM работает с существующими лидами листа «Лиды» [этой таблицы](https://docs.google.com/spreadsheets/d/1RLtgu9TSvk9tQRVE-OhaWzX4Pgj19OH0z36htA8JxiI/edit?gid=29515803#gid=29515803). Сайт открывается по ссылке без входа. Список лидов появляется после подключения Google-аккаунта, которому доступна таблица. Данные лидов не включены в сборку сайта.

## Локальный запуск

Дважды щёлкните [start-crm.cmd](start-crm.cmd), затем откройте **http://localhost:4173/**. При первом запуске скрипт установит зависимости. Альтернатива: `npm install`, затем `npm run dev` в этой папке.

## Подключение Google

1. В [Google Cloud Console](https://console.cloud.google.com/apis/credentials) выберите проект, включите **Google Sheets API** и настройте экран согласия OAuth. Если приложение в тестовом режиме, добавьте аккаунт, которым будете подключать таблицу, в список тестовых пользователей.
2. Создайте **OAuth Client ID** типа **Web application**. В **Authorized JavaScript origins** добавьте `http://localhost:4173` и точный адрес опубликованного сайта Vercel, например `https://имя-проекта.vercel.app`. Адрес Vercel должен быть указан без завершающего `/`.
3. В CRM откройте «Подключение», вставьте Client ID и нажмите «Подключить Google». Выберите Google-аккаунт с правом редактирования таблицы.

CRM запрашивает область `https://www.googleapis.com/auth/spreadsheets`, чтобы читать и изменять исходный лист. Client ID хранится в браузере, токен доступа — только в памяти вкладки. После истечения сессии подключите аккаунт снова. Client ID можно также задать при сборке через `VITE_GOOGLE_CLIENT_ID`.

## Работа с лидами

- Выберите лида и нажмите «Изменить в таблице». Можно менять поля существующей строки; столбец «№» и заголовки не редактируются. Добавление и удаление строк не предусмотрено.
- При сохранении CRM проверяет номер строки, текущие значения изменяемых ячеек и формулы. Если строка переместилась, ячейка была изменена кем-то ещё или содержит формулу, запись отменяется: обновите данные и повторите правку. После успешной записи CRM перечитывает лист.
- Пока вкладка видима и Google подключён, CRM проверяет изменения в листе каждые 5 секунд; при возврате на вкладку проверяет сразу. Кнопка источника данных запускает ручное обновление.
- «Моя заметка» хранится только в этом браузере. Локальный адрес и адрес Vercel имеют разное хранилище; для переноса заметок скачайте JSON в разделе «Подключение» и восстановите его на новом адресе.

Для чтения без Google можно вручную загрузить CSV листа «Лиды» в разделе «Подключение». Редактирование через CSV не записывает изменения в исходную таблицу.

## Vercel и доступ

Для Vercel предусмотрена сборка `npm run build:vercel` с папкой результата `dist/client`. Файл со старым снимком лидов исключён из исходников, отправляемых Vercel, и не используется приложением. Опубликованный адрес без входа может открыть любой, кто его знает. Это ссылка без защиты страницы; доступ к данным и записи определяют права Google-аккаунта на таблицу.

При загрузке исходников в GitHub `src/snapshot.json` также исключается через `.gitignore`: это локальная копия лидов, которая не нужна для запуска или проверки проекта.
